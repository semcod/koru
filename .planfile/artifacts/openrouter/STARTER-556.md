# STARTER-556: R-F3.1: Single-source versioning via setuptools dynamic version

model: qwen/qwen3-coder-next

## Prompt

goal bumps VERSION+pyproject+__init__+uv.lock in lockstep; drift causes failed publishes (tillm 0.1.36 incident). Switch semcod packages to dynamic = [version] reading VERSION, eliminating the sync class entirely.

---
Deliverable: a concrete, ordered action plan with exact shell commands and file paths where applicable, short enough to execute directly. State assumptions explicitly; do not pad.

## Answer

**Assumptions**  
1. Project uses `semver`-style versioning in a top-level `VERSION` file (e.g., `0.1.36`).  
2. `pyproject.toml` currently has `dynamic = ["version"]` and a `tool.uv`/`tool.poetry` section referencing `VERSION` manually (or via script).  
3. `__init__.py` contains a hardcoded `__version__ = "..."` (or imports from a `version.py`).  
4. `uv.lock` is generated by `uv` and must stay in sync with `pyproject.toml` version.  
5. Goal: eliminate manual sync (e.g., no `scripts/sync_version.py` or `setuptools-scm`), use `dynamic = ["version"]` with `version = { read = "VERSION" }` (PEP 621 + uv 0.4+ support).  
6. All packages are in a monorepo under `src/` (adjust if different).  

---

### Action Plan (≤10 steps, executable)

1. **Ensure `VERSION` file exists and is valid**  
   ```bash
   echo "0.1.37" > VERSION  # or verify current version
   ```

2. **Update `pyproject.toml`**  
   Replace any static `version = "..."` or `tool.poetry.version` with:  
   ```toml
   [project]
   dynamic = ["version"]
   
   [tool.uv]
   # Optional: if using uv for publishing, ensure it reads VERSION
   # (uv respects PEP 621 dynamic version via `version.read` as of 0.4.20+)
   ```
   Add PEP 621-compliant dynamic version source:  
   ```toml
   [project]
   dynamic = ["version"]
   
   [tool.uv]
   # No extra config needed — uv auto-reads `version.read` from [project]
   
   [project]  # if not already present
   version = { read = "VERSION" }
   ```
   > ✅ **Critical**: `version = { read = "VERSION" }` must be under `[project]`, *not* `[tool.*]`.

3. **Remove hardcoded `__version__` from `__init__.py`**  
   Replace:  
   ```python
   __version__ = "0.1.36"
   ```  
   With:  
   ```python
   from importlib.metadata import version, PackageNotFoundError
   try:
       __version__ = version("your-package-name")
   except PackageNotFoundError:
       __version__ = "0.0.0"  # fallback for dev installs
   ```

4. **Delete any legacy sync scripts or `version.py`**  
   ```bash
   rm -f scripts/sync_version.py src/your_package/version.py
   ```

5. **Regenerate `uv.lock` to embed dynamic version**  
   ```bash
   uv lock --no-build-isolation  # ensures lock reflects dynamic version
   ```

6. **Verify lockfile version matches `VERSION`**  
   ```bash
   grep -A1 '\[metadata\]' uv.lock | grep 'version' | cut -d'"' -f2
   # Should match $(cat VERSION)
   ```

7. **Test install + version resolution**  
   ```bash
   uv pip install -e . && python -c "import your_package; print(your_package.__version__)"
   # Output must equal $(cat VERSION)
   ```

8. **Update CI/CD publish step**  
   Ensure publish uses `uv publish` (or `twine` *after* `uv build`), *not* manual version injection:  
   ```yaml
   # .github/workflows/publish.yml
   - run: uv build
   - run: uv publish --token ${{ secrets.PYPI_TOKEN }}
   ```

9. **Add pre-commit hook to prevent drift**  
   ```bash
   # .pre-commit-config.yaml
   repos:
     - repo: local
       hooks:
         - id: version-sync
           name: Check VERSION == pyproject.toml version
           entry: bash -c 'v=$(cat VERSION); p=$(grep -E "^version = " pyproject.toml | cut -d"\"" -f2); [ "$v" = "$p" ] || { echo "Drift: VERSION=$v, pyproject=$p"; exit 1; }'
           language: system
           files: ^VERSION$|^pyproject\.toml$
   ```

10. **Document in `CONTRIBUTING.md`**  
    ```markdown
    ## Versioning  
    - Version is defined **only** in `VERSION`.  
    - `pyproject.toml` uses `version = { read = "VERSION" }`.  
    - `__init__.py` reads version via `importlib.metadata`.  
    - Run `uv lock` after changing `VERSION`.
    ```

---

**Result**: `VERSION` is the single source of truth. `pyproject.toml`, `__init__.py`, and `uv.lock` auto-sync via PEP 621 + uv. No manual sync class needed.
