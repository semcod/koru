Tips when sharing fails

NotAllowedError / Permission denied can mean:

  • You clicked Cancel in the browser's screen-share dialog.
  • The page is not on localhost / 127.0.0.1 nor served over HTTPS. getDisplayMedia requires a secure context. Open on the machine running koru.
  • Wayland (GNOME 49): the xdg-desktop-portal dialog appeared and was dismissed. Re-click Share screen, click on the GNOME portal popup, pick a monitor, then Share.
  • Chromium on Wayland needs PipeWire screencast (default since Chrome 116). If disabled, enable chrome://flags/#enable-webrtc-pipewire-capturer.
  • Firefox on Wayland: enable media.webrtc.camera.allow-system-permissions-prompt in about:config.
  • macOS: System Settings → Privacy & Security → Screen Recording must include the browser, then restart it.
